Ожидаемая структура Excel-файла:

```
Дата операции
Дата платежа
Номер карты
Статус
Сумма операции
Валюта операции
Сумма платежа
Валюта платежа
Кэшбэк
Категория
MCC
Описание
Бонусы (включая кэшбэк)
Округление на инвесткопилку
Сумма операции с округлением

```

типы данных:
```
 'dtypes': {'MCC': dtype('float64'),
            'Бонусы (включая кэшбэк)': dtype('int64'),
            'Валюта операции': dtype('O'),
            'Валюта платежа': dtype('O'),
            'Дата операции': dtype('O'),
            'Дата платежа': dtype('O'),
            'Категория': dtype('O'),
            'Кэшбэк': dtype('float64'),
            'Номер карты': dtype('O'),
            'Округление на инвесткопилку': dtype('int64'),
            'Описание': dtype('O'),
            'Статус': dtype('O'),
            'Сумма операции': dtype('float64'),
            'Сумма операции с округлением': dtype('float64'),
            'Сумма платежа': dtype('float64')}
```
